# Programatic-Era-Of-Mass-Video-Production

Programmatic Era of Mass Video Production automates video creation using programming and AI technologies. The project aims to streamline video production, reduce manual effort, and enable scalable content generation through automated workflows, making video creation faster, more efficient, and accessible.

## Setup

1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key.
3. If you run `test_openai.cjs`, set `POLLINATIONS_API_KEY` as an environment variable. Do not hardcode it in source files.
4. Run the app:
   `npm run dev`
